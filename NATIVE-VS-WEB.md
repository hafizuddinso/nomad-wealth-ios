# Native app status

This project is a native iOS app built with SwiftUI.

It does not:
- open the website inside the app
- use WKWebView
- require Vercel to display its screens

Data is currently stored locally on the iPhone. It is not synchronized with the website or another device yet.

Accurate announcement:

“Nomad Wealth is now available as a native iPhone test app. A responsive web version is also available for Android and mobile browsers.”

Do not say “Available on the App Store” until Apple approves and publishes it.
Do not say “Android app available” until an APK/AAB is built.
